# tree-sitter-fram

Fram grammar for [tree-sitter](https://github.com/tree-sitter/tree-sitter).

## State of the project.

### Grammar

Currently, the grammar closely mirrors the parser of [`dbl`](https://github.com/fram-lang/dbl).
Dbl's parser is rather ugly, and, by extension, so is this one. I hope to rewrite it once we write the parser for the Fram compiler.
